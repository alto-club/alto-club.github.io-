# חלק ד׳: UX לגיל 65+ - Best Practices מפורטות

## 4.1 טיפוגרפיה ונגישות

| פרמטר | ערך מומלץ | הסבר |
|-------|----------|-------|
| גודל פונט גוף | 18-20px | מינימום 16px, אידיאלי 18-20px |
| גודל כותרות H1 | 42-48px | בולט ומזמין |
| גודל כותרות H2 | 32-36px | היררכיה ברורה |
| גודל כותרות H3 | 24-28px | תת-כותרות |
| גובה שורה | 1.6-1.8 | נשימה בין שורות |
| משקל פונט | Regular 400, Bold 700 | ללא Light/Thin |
| גופן מומלץ | Heebo / Assistant | גופני RTL נקיים ונגישים |

## 4.2 ניגודיות וצבעים

```
✅ דרישות WCAG AA לגיל מבוגר:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
• יחס ניגודיות טקסט רגיל: 4.5:1 (מינימום)
• יחס ניגודיות טקסט גדול: 3:1
• המלצה לגיל 65+: 7:1 ומעלה

❌ להימנע:
• טקסט אפור בהיר על לבן
• אנימציות מהירות/מהבהבות
• הבדלי צבע בלבד (ללא צורה/טקסט)
• גרדיאנטים מורכבים מאחורי טקסט
```

## 4.3 כפתורים ואלמנטים אינטראקטיביים

```

│  מרווח בין כפתורים:  16px מינימום               │

└─────────────────────────────────────────────────┘
```
