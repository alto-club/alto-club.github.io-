## 3. הגנת פרטיות - חוק ישראלי ו-GDPR

### 3.1 חוק הגנת הפרטיות הישראלי (תשמ"א-1981)

#### עיקרי החוק ותיקון מס' 14 (נכנס לתוקף 2025):

```
╔══════════════════════════════════════════════════╗
║          תיקון 14 - שינויים משמעותיים             ║
║                                                   ║
║  • כניסה לתוקף: אוגוסט 2025                      ║
║  • קנסות: עד ₪3.4 מיליון לארגון                 ║
║  • מינוי ממונה פרטיות: חובה לארגונים גדולים      ║
║  • DPIA: הערכת השפעה על פרטיות - מומלץ          ║
╚══════════════════════════════════════════════════╝
```

#### חובת רישום מאגר מידע:
LUMINA **חייבת** לרשום מאגר מידע ברשות להגנת הפרטיות כי:
- מחזיקה נתוני משתמשים (שם, כתובת, גיל, תמונות)
- מספר משתמשים צפוי עולה על 10,000
- כולל "מידע רגיש" (גיל, מצב בריאות משתמע)

**תהליך רישום מאגר:**
```
1. כניסה לאתר רשות הגנת הפרטיות
2. מילוי טופס רישום מאגר מידע
3. תשלום אגרה (כ-₪1,000-₪2,500 בהתאם לסוג)
4. קבלת מספר מאגר
5. ציון מספר המאגר בתנאי השימוש ובאפליקציה
```

#### נתונים שנחשבים "מידע רגיש" ב-LUMINA:
| סוג מידע | רגישות | טיפול נדרש |
|----------|---------|-----------|
| שם ותמונה | בסיסי | הסכמה רגילה |
| גיל (65+) | רגיש | הסכמה מפורשת |
| מצב בריאות (אם נאסף) | רגיש מאוד | הסכמה מפורשת + הצפנה |
| סיפורי חיים ("הסיפור שלי") | בינוני-רגיש | הסכמה לפרסום |
| מיקום גיאוגרפי | בינוני | הסכמה והגבלת שיתוף |
| תמונות שהועלו | בינוני | מדיניות ברורה |

#### מדיניות פרטיות - רכיבים חובה:
```
☑ מי אוסף את המידע (שם החברה, כתובת, איש קשר)
☑ מה נאסף ולמה (תכלית)
☑ כמה זמן שומרים (תקופת שמירה)
☑ למי מועבר המידע (צדדים שלישיים)

☑ שימוש ב-Cookies
☑ אבטחת מידע
☑ יצירת קשר עם הממונה על פרטיות
```

### 3.2 GDPR - תקנת האיחוד האירופי

#### האם LUMINA כפופה ל-GDPR?

```
LUMINA כפופה ל-GDPR אם:
✓ משתמשים מאירופה נרשמים לשירות
✓ הפלטפורמה מיועדת (גם) לאיחוד האירופי
✓ עיבוד נתוני אזרחי EU - בכל מקום

LUMINA אינה כפופה ל-GDPR אם:
✗ פונה אך ורק לתושבי ישראל
✗ אין שיווק לאיחוד האירופי
✗ אין תשתית בגרמניה/צרפת וכו'
```

**המלצה מעשית:** בנה את LUMINA כ-GDPR-ready מלכתחילה:
- עלות זניחה בשלב ההקמה
- מאפשר הרחבה עתידית לאירופה
- מהווה "רשת ביטחון" למשתמשים עם אזרחות כפולה

#### דרישות GDPR מרכזיות ל-LUMINA:

**א. בסיס חוקי לעיבוד מידע:**
- **הסכמה** (Consent) - ברורה, חופשית, ניתנת לביטול
- **חוזה** - לביצוע שירות
- **אינטרס לגיטימי** - זהירות בשימוש זה

**ב. זכויות נושאי מידע:**
```
• זכות גישה (Access) - לקבל עותק של הנתונים
• זכות תיקון (Rectification)
• זכות מחיקה "הזכות להישכח" (Erasure)
• זכות להגביל עיבוד (Restriction)
• זכות ניידות נתונים (Portability)
• זכות התנגדות (Objection)
```

**ג. Data Protection Officer (DPO):**
- **חובה** אם מעבדים נתונים בקנה מידה גדול של "קטגוריות מיוחדות"
- לגיל שלישי - שקול מינוי יזום

**ד. Data Breach Notification:**
- דיווח לרשות הפיקוח תוך **72 שעות**
- דיווח לנפגעים ללא דיחוי

## 5. נגישות דיגיטלית - תקן SI 5568

### 5.1 תקן הנגישות הישראלי לאתרי אינטרנט

#### מה זה SI 5568?
תקן ישראלי מחייב לנגישות אינטרנט, המבוסס על **WCAG 2.1** הבינלאומי. מחייב אתרים ואפליקציות של עסקים ושירותים ציבוריים.

#### מי חייב לעמוד בתקן?
