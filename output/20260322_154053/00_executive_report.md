# דוח מנהלים מקיף — LUMINA
### פלטפורמה חברתית-תרבותית לגיל 65+ בישראל

**תאריך:** יוני 2025 | **סיווג:** סודי — לשימוש פנימי ולמשקיעים בלבד

## 1. 📋 תקציר מנהלים

> **1.1 מיליון ישראלים מעל גיל 65 — ואין אף פלטפורמה דיגיטלית כוללת שמשרתת אותם.**

כ-30% מהקשישים בישראל חווים בדידות משמעותית. העלות למערכת הבריאות: מיליארדי שקלים בשנה. במקביל, 70-75% מבני 65-74 כבר פעילים דיגיטלית, ו-85% מהם מחזיקים סמארטפון. **הפער בין הביקוש להיצע הוא עצום.** LUMINA מציעה מרחב חיים דיגיטלי — לא "אפליקציה לקשישים" — המשלב יוגה, משחקים קוגניטיביים, ציור, ו"הסיפור שלי" (כלי מורשת אישית), עם קהילה חיה ותומכת. המודל העסקי (Freemium + B2B מוסדי) מאפשר צמיחה בת-קיימא עם אימפקט חברתי מדיד. שוק הטכנולוגיה לגיל השלישי בעולם צפוי להגיע ל-2 טריליון דולר עד 2030 — ו-LUMINA שואפת לתפוס את המיקום המוביל בישראל.

## 2. 🎯 חמש ההחלטות הקריטיות

### החלטה #1: מבנה משפטי — חברה לתועלת הציבור (חל"צ)

| פרמטר | פירוט |
|--------|--------|
| **ההחלטה** | הקמת חל"צ (לא עמותה, לא חברה רגילה) |
| **למה עכשיו** | כל שלב אחר (גיוס כספים, שותפויות, רישיונות) תלוי בכך |
| **הנימוק** | חל"צ משלבת ייעוד חברתי עם קיימות כלכלית: ניתן לגבות דמי מנוי ולהפיק הכנסות, ובמקביל ליהנות מאמינות ציבורית גבוהה (קריטי לאוכלוסייה שנזהרת מהונאות), גישה למענקי משרד הרווחה ורשויות מקומיות, הגנה על נכסי המייסדים, ושותפויות קלות עם קופות חולים ובתי חולים |
| **חלופה שנדחתה** | חברה בע"מ — מיסוי מלא, פחות אמינות חברתית; עמותה — גמישות מסחרית מוגבלת |
| **עלות משוערת** | 8,000-15,000 ₪ (רישום + עו"ד) |
| **אחראי** | מייסד/ת + עו"ד חברות |

### החלטה #2: מודל הכנסות — Freemium + B2B מוסדי

| פרמטר | פירוט |
|--------|--------|
| **ההחלטה** | שכבת חינם → מנוי "כסף" (59 ₪/חודש) → מנוי "זהב" (99 ₪/חודש) + חוזים מוסדיים |
| **למה עכשיו** | מודל ההכנסות מכתיב את ארכיטקטורת הפלטפורמה, עיצוב ה-UX, ותכנון התוכן |
| **הנימוק** | **שכבת חינם** מורידה חסם כניסה — קריטי לאוכלוסייה שמהססת ומתקשה עם תשלומים דיגיטליים. יעד: 30-40% המרה לתשלום. **הערוץ המוסדי** (בתי אבות, קופות חולים, עיריות) מספק הכנסה יציבה וחזויה — מחיר 800-8,000 ₪/חודש למוסד, עם ~600 מוסדות פוטנציאליים ו-4 קופות חולים. זהו מנוע ההכנסה העיקרי בטווח הבינוני |
| **סיכון** | תמחור שגוי — יש לבדוק עם 50 משתמשי בטא לפני נעילה |
| **יעד שנה 1** | 1,500 מנויים משלמים + 10 חוזים מוסדיים |

**פירוט מנויים:**

| מסלול | מחיר חודשי | מחיר שנתי | מה כלול |
|--------|-----------|-----------|---------|
| **חינם** | 0 ₪ | — | 5-10 שיעורים מוקלטים/חודש, קהילה בסיסית, טעימת "הסיפור שלי" |
| **"לומינה כסף"** | 59 ₪ | 598 ₪ | כל השיעורים החיים, ארכיון מלא, קבוצות וסדנאות |
| **"לומינה זהב"** | 99 ₪ | 998 ₪ | כל ה"כסף" + ליווי אישי חודשי, "הסיפור שלי" מלא, גישה מוקדמת לאירועים, הנחות |

### החלטה #3: ארכיטקטורה טכנולוגית — PWA + Native Hybrid

| פרמטר | פירוט |
|--------|--------|
| **ההחלטה** | Progressive Web App כברירת מחדל + אפליקציית Native ב-React Native |
| **למה עכשיו** | ההחלטה הטכנולוגית קובעת לוח זמנים, תקציב פיתוח ואיכות חוויית משתמש |
| **הנימוק** | **PWA** מאפשר גישה מדפדפן ללא הורדה — חסם עצום לגיל 65+ שמתקשים להתקין אפליקציות. **Native** נותן חוויה מיטבית למשתמשים מתקדמים ונוטיפיקציות. **Stack מומלץ:** Next.js 14+ (Frontend), NestJS (Backend), Tailwind + Radix UI (נגישות מובנית, WCAG 2.1, RTL מלא), i18next (עברית + ערבית) |
| **עלות שלב 1** | 250,000-400,000 ₪ (MVP 3-4 חודשים) |
| **הדגש הקריטי** | נגישות תקן SI 5568 מובנית מהיום הראשון — לא "נוסיף אחר כך" |

### החלטה #5: אסטרטגיית כניסה לשוק — B2B2C דרך קופות חולים

| פרמטר | פירוט |
|--------|--------|
| **ההחלטה** | ערוץ גיוס ראשי: שותפויות עם קופות חולים + עיריות; ערוץ משני: מפה-לאוזן + Facebook |
| **למה עכשיו** | שותפויות מוסדיות דורשות 3-6 חודשי משא ומתן — יש להתחיל מיד |
| **הנימוק** | **45%** מהלקוחות החדשים צפויים להגיע מהפניית חבר/ה. **30%** מקופות חולים (מכבי Care, כללית מושלם, מאוחדת Active). קהל 65+ מקבל החלטות על בסיס אמון — הפניה מרופא משפחה או קופ"ח שווה פי 10 מפרסומת. **91%** מהקהל פעילים ב-WhatsApp — זה ערוץ ההפצה המרכזי |
| **פעולה ראשונה** | פגישה עם מנהלי חדשנות ב-2 קופות חולים + 3 עיריות גדולות |
| **יעד שנה 1** | 2 שותפויות קופ"ח + 5 עיריות + 10 בתי אבות |
