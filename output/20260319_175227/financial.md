# חלק ו': נקודת איזון

## 6.1 חישוב Break-Even

### הנחות בסיס:
- הכנסה חודשית ממוצעת למנוי: **₪89** (מחיר "פריחה")
- עלות תפעול חודשית שנה 1: **₪280,000** (כ"א + שיווק + תשתיות)
- **Gross Margin**: ~75% (עלות ישירה: 25% = תוכן, שרתים, תמיכה)
- **הכנסה נטו למנוי**: ₪89 × 75% = **₪66.75**

### חישוב:

```
נקודת איזון = עלות תפעול חודשית ÷ הכנסה נטו למנוי

₪280,000 ÷ ₪66.75 = 4,194 מנויים
```
